# Low-rank covariance subspaces

`dfckit.connectivity.LowRankCovariance` measures whether multivariate ROI
activity inside a fixed window is organized around a small covariance
subspace. It operates on `TimeSeriesRun`, so windows and comparisons between
adjacent windows remain bounded by XCP-D censor segments.

This method describes shared covariance geometry. It does not estimate the
direction, amount, or causal route of information transfer between ROIs.

## Window definition

The estimator accepts an arbitrary window `length`, `step`, ordered collection
of `ranks`, and optional temporal `split`. Each window is generated by
`TimeSeriesRun.windows`; no window crosses a gap in the original frame indices.
The default split is the integer midpoint. Both halves must contain enough
frames to estimate every requested rank.

Within each PCA fit, every ROI is centered and divided by its population
standard deviation (`ddof=0`). If `Z` is the standardized frames-by-ROI matrix,
its singular value decomposition is

```text
Z = U S V.T
```

The first `K` columns of `V` form the rank-`K` ROI covariance basis. Squared
singular values are normalized to proportions `p_i` for the metrics below.

## Window metrics

Effective rank summarizes how broadly variance is distributed:

```text
effective_rank = exp(-sum(p_i * log(p_i)))
```

Top-`K` eigen concentration is `sum(p_i for i <= K)`. Greater concentration
means that fewer covariance dimensions account for more of the standardized
window variance.

Held-out `R2` tests whether a subspace fitted in one temporal half reconstructs
the other half. The test half is standardized using the training half's mean
and scale. The estimator averages first-half-to-second-half and
second-half-to-first-half values. Negative values are valid and mean that the
learned subspace reconstructs the held-out standardized samples worse than a
zero prediction.

Split similarity compares the independently fitted bases from the two halves:

```text
similarity(L, R) = ||L.T @ R||_F^2 / K
```

It ranges from zero to one and is unchanged by component signs or rotations
within the same subspace. The corresponding distance is
`sqrt(1 - similarity)`.

## Window and run bases

For every requested rank, the result retains the full-window bases in
`window_bases`. A run-level basis is formed by averaging the projection
matrices `B @ B.T` across windows and taking the leading eigenvectors of that
mean projector. Projection averaging prevents arbitrary PCA signs and
within-subspace rotations from changing the aggregate geometry.

`adjacent_similarity` compares consecutive generated windows only when their
`segment_id` is identical. The paired window indices are explicit in
`adjacent_left_windows` and `adjacent_right_windows`; a censor gap therefore
cannot silently become a temporal transition.

## Example

```python
from dfckit.connectivity import LowRankCovariance
from dfckit.io import load_xcpd_run

loaded = load_xcpd_run(
    "/path/to/xcp_d",
    subject="sub-001",
    session="off",
    atlases=("Glasser", "Tian"),
    space="MNI152NLin2009cAsym",
    tr=0.8,
)

result = LowRankCovariance(
    length=96,
    step=96,
    ranks=(1, 2, 4),
).transform(loaded.run)

k4 = result.rank_index(4)
print(result.eigen_concentration[:, k4].mean())
print(result.heldout_r2[:, k4].mean())
print(result.adjacent_similarity[:, k4].mean())
```

Run bases may be compared with `subspace_similarity` or
`subspace_distance`. A healthy-reference basis must be fitted using only the
declared reference participants; healthy-reference fitting and participant
provenance are a separate `v0.2` utility rather than implicit behavior of this
estimator.
